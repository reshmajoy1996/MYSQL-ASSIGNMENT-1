# MYSQL-ASSIGNMENT-1
Employee Database Management System – MySQL

This project demonstrates the use of DDL (Data Definition Language) commands and SQL constraints in MySQL. It includes the creation and management of an Employee Database with three related tables: Departments, Location, and Employees.

The project covers:

Database and table creation using CREATE
Table modification using ALTER
Table renaming using RENAME
Removing records using TRUNCATE
Deleting tables and databases using DROP
Constraints such as PRIMARY KEY, UNIQUE, NOT NULL, CHECK, DEFAULT, AUTO_INCREMENT, and FOREIGN KEY
Establishing relationships between Employees, Departments, and Locations

This project was created as part of my SQL/Data Analytics learning project
